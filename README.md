# CampusFind 🎓
### Campus Lost and Found Management System

## 📌 About the Project
CampusFind is a web-based platform designed to help college students report, find, and claim lost items on campus. It makes the process simple, organized, and convenient.

## 🎯 Objectives
- Help students find their lost belongings.
- Allow users to post lost and found items.
- Make communication between users easier through contact requests.
- Reduce the time and effort needed to recover lost items.

## ✨ Features
- **User Authentication:** Sign up and sign in.
- **Lost Items:** Post details of missing items.
- **Found Items:** Report items found on campus.
- **Item Posts:** View lost and found posts.
- **Contact Requests:** Request contact with the person who posted an item.
- **User-Friendly Interface:** Simple and easy-to-use design.

## 🛠️ Technologies Used
- HTML – Website structure
- CSS – Styling and layout
- JavaScript – Functionality
- Supabase – Authentication and database

## ⚙️ How It Works
1. Users sign up or sign in.
2. They create a post about a lost or found item.
3. Other students view the available posts.
4. Interested users request contact to help return the item.

## 🌟 Benefits
- Saves time in finding lost belongings.
- Improves communication among students.
- Provides an organized platform for lost and found items.
- Encourages students to return items to their owners.

## 🚀 Future Scope
- Image-based item matching.
- Search and filter options.
- Notifications for matching items.
- Mobile-friendly improvements.

## 👩‍💻 Project Purpose
CampusFind aims to create a helpful campus community where students can easily report, locate, and recover lost belongings.
